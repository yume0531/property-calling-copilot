# Property Calling Copilot

房地产 Calling 用的 MVP：4 个核心问题 + 1 个兴趣钩子 → 项目匹配 → Sales Hook。

## 运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 数据

项目资料放在 `projects.csv`。以后用你的真实 IQI Project Database 替换示例数据。
